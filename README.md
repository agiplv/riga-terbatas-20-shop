# riga-terbatas-20-shop

Statiska vizītkartes mājaslapa komercplatības nomai Tērbatas ielā 20, Rīgā.

## Publicēšana ar GitHub Pages

1. Atver repozitorija **Settings**.
2. Sadaļā **Pages** izvēlies:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (un `/root`)
3. Saglabā izmaiņas un pagaidi publicēšanu.
4. Lapa būs pieejama pie repozitorija norādītās GitHub Pages adreses.
